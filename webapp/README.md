# 五腧穴·子午流注計算工具 — v1 本機原型

本地優先的針灸取穴計算工具原型。不連網、不呼叫第三方在線 API，記錄僅存本機瀏覽器。

## 執行方式

- 線上預覽（GitHub Pages）：https://lemon74088.github.io/wushu-ziliuzhu-app/webapp/index.html
- 直接雙開 `index.html`（file:// 可運行，無建置步驟）。
- 或本機起服務：`python -m http.server 8931`，再開 `http://127.0.0.1:8931/index.html`。

## 操作流程

- 開頁自動帶今日日期與目前時辰，直接算出預設病經的母穴／子穴，無需先按計算。
- 變更病經、虛實、規則、日期或時辰，結果即時更新（不寫入歷史）；按「記錄本次結果」才存入 IndexedDB。
- 母子補瀉須指定病經；純按時辰開穴的納甲、納子法仍為待研究占位。

繁簡切換為字元級對照：未對照到的字保留原字形；經脈、穴位等專有名詞以教材繁體為準。歷史快照內存的輸入／結果為當時繁體原文，檢視時依目前語言顯示。

## 資料說明

- 十二經五輸穴與穴位五行配屬，核對自教材五輸穴表（見 `../references/五輸穴五行配屬核對.md`）。
- 陰經：井木·滎火·輸土·經金·合水；陽經：井金·滎水·輸木·經火·合土。
- 本工具為經脈層面的補瀉方向參考，不直接等同選穴處方；正式上線前，穴位與流派規則須由醫師覆核典籍出處。

## 歷史記錄欄位

每則記錄保存：記錄編號、建立時間、輸入（日期／時辰／病經／虛實／模式）與日曆快照（干支、農曆、節氣、生肖）、輸出結果、推演步驟、引擎版本、規則版本、資料版本、曆法庫版本、驗證狀態、警告與規則快照。匯出為 JSON 供使用者自行備份。
